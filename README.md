## 📌 Sobre o Projeto

Este é um projeto de **calculadora no terminal**, feita em **Python puro**. Com ele, é possível realizar:

- ➕ Adição  
- ➖ Subtração  
- ✖️ Multiplicação  
- ➗ Divisão  

Ideal para quem está iniciando na programação!

---

## 🛠️ Tecnologias Utilizadas

- [Python 3.x](https://www.python.org/)
- Terminal (CLI)

---

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/kauevictor30/Project-calculadora.git
```

2. Acesse a pasta:

```bash
cd Project-calculadora
```

3. Execute o script:

```bash
python calculadora.py
```

⚠️ Certifique-se de ter o **Python 3** instalado na sua máquina.
